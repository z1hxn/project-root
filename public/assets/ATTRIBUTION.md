## Project Root mark

The existing Project Root mark is retained unchanged: #c6d995 rounded square, #1b2215 north-east arrow, derived from the Lucide `ArrowUpRight` icon (ISC license, https://lucide.dev/license). Raster exports are available under `/brand/` at 1024, 512 and 256 pixels. SVG is the resolution-independent source.
