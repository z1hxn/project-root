# [Project Root 사내 문서] 1-1 문서 체계와 정보 취급

문서 번호: PR-OPS-1-1 | 담당: 운영지원실 | 적용일: 2026-08-10 | 개정: 2.1 | 등급: 사내

## 목적과 적용 범위
PROJECT ROOT는 공개 웹 자료와 내부 운영 기록을 함께 조사한다. 공개된 사실과 내부 시스템에서 관찰한 사건을 섞어 기록하면 나중에 근거를 검증하기 어렵다. 이 문서는 워크스테이션을 사용하는 조사관, 개발 운영 담당자, 검토자가 공통으로 따르는 문서 분류와 기록 원칙을 정한다. 특정 사건의 처리 지시서는 아니다.

## 문서 분류
- 1번대: 조직 공통 절차와 조사 기록 원칙. 보고서와 수집물의 출처를 구분한다.
- 2번대: 관리형 Debian/KDE 워크스테이션의 사용 기준과 패키지 관리.
- 3번대: 개발팀 서비스, 파일 공유, 명령행 도구의 운영 참고서.
- 4번대: 로그 보존, 계정 식별, 장애 및 보안 검토 절차.

번호는 게시 순서를 나타내며 우선순위나 사건 번호를 뜻하지 않는다. 같은 사안의 문서는 최신 개정본을 기준으로 읽고, 오래된 별도 메모가 있더라도 본문과 충돌하면 문서 담당자에게 확인한다. 문서에 없는 주소나 계정 권한을 추측해서 사용하지 않는다.

## 자료의 출처 표시
보고서의 사실 문장은 원본 위치, 관찰 시각, 기록의 시간대, 확보 경로를 함께 적는다. 공개 웹 자료는 URL과 게시 주체를 남기고, 내부 파일은 서버·공유·상대 경로와 파일명을 남긴다. 다운로드본을 수정해 해석한 경우 원본과 개인 메모를 별도로 보관한다. 정황만으로 실제 사용자나 의도를 확정하지 않는다.

개인 홈 디렉터리는 작업 사본 저장 공간이다. 회사의 공유 저장소를 로컬 폴더처럼 이동하거나 이름을 변경하지 않는다. 공유 자원의 운영 설정은 개발 인프라 담당자가 관리한다.

## 열람과 보관
사내 문서는 조직 구성원의 업무 참고용이며 외부 게시물에 그대로 복사하지 않는다. 인증 토큰이나 비밀번호를 보고서, 개인 메모, 명령 이력에 적지 않는다. 조사 종료 후에도 근거가 된 원본의 위치가 재확인 가능해야 한다. 접근 실패를 권한 우회 지시로 해석하지 않는다.

관련 문서: 1-2 조사 기록 작성, 2-1 워크스테이션 표준, 4-1 운영 기록 보존.
