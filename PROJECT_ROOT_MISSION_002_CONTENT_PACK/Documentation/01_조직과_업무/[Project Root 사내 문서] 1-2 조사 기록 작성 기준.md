# [Project Root 사내 문서] 1-2 조사 기록 작성 기준

## 조사 노트의 기본 단위
한 줄의 로그는 사건 전체가 아니다. 먼저 관찰한 사실, 비교에 사용한 기준선, 가능한 설명, 아직 확인하지 못한 내용을 분리해서 기록한다. 시간은 원본의 표기와 변환한 시간대를 함께 적는다. 01:30 KST와 02:14 KST처럼 가까운 시각이라도 계정, 세션, 인증 방식, 요청 대상이 다르면 별개의 활동일 수 있다.

## 권장 작성 순서
1. 최초 통보의 주장과 확인 가능한 사실을 나눈다. 통보가 정확하다는 가정으로 시작하지 않는다.
2. 같은 계정 또는 서비스의 이전 활동을 찾아 평소 출발지·시간·접속 수단을 기록한다.
3. 해당 시각의 인증 이벤트를 서비스 기록, 작업 스케줄, 변경 이력과 대조한다.
4. 서로 일치하는 단서와 설명되지 않는 차이를 별도 문단에 적는다.
5. 공개 활동 자료가 있다면 게시 시각과 작성 주체를 확인한다. 공개 활동만으로 내부 세션의 사용자를 단정하지 않는다.

## 증거 목록 예시
| 항목 | 적을 내용 |
| --- | --- |
| 원본 | 호스트, 공유 이름, 원격 경로 또는 공개 URL |
| 확보 | 관찰 날짜, 다운로드 위치, 도구 |
| 시간 | 원본 타임스탬프와 시간대 |
| 관계 | 어느 주장을 지지하거나 반박하는지 |
| 한계 | 누락된 기간, 권한 부족, 식별되지 않은 사용 주체 |

보고서에는 자료가 존재한다는 것과 자료가 특정 결론을 증명한다는 것을 구분해 쓴다. 의심스러운 세션을 발견해도 계정 소유자에게 곧바로 책임을 돌리지 않는다. 추가 확인이 필요한 항목은 확인 주체와 다음 절차를 명시한다.
