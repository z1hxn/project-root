# Internal Resources Overview

PROJECT ROOT 워크스테이션은 로컬 파일 외에도 조직 내부의 문서, 개발 스토리지 및 빌드 리소스에 접근할 수 있다. 일반 사용자는 Dolphin의 **Network** 항목에서 자신에게 공개된 리소스를 확인할 수 있다.

내부 리소스는 목적에 따라 분리되어 있으며 모든 서비스가 동일한 접근 방식을 사용하지는 않는다. 연결 문제가 발생하면 먼저 `03_Network` 문서를 확인한다.

보안 사고 검토를 위해 부여된 임시 권한은 읽기 전용일 수 있다. 권한 오류가 발생했다고 해서 우회하거나 다른 계정을 사용하지 말고 사건 범위와 할당된 접근 권한을 확인한다.
