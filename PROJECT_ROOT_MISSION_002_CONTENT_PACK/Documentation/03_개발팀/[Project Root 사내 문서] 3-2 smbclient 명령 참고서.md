# [Project Root 사내 문서] 3-2 smbclient 명령 참고서

문서 번호: PR-DEV-3-2 | 담당: 개발 인프라팀 | 적용일: 2026-09-14 | 개정: 2.3 | 등급: 사내

## 용도와 사전 조건
`smbclient`는 Samba가 제공하는 SMB/CIFS 명령행 클라이언트다. 원격 공유의 디렉터리 확인, 파일 내려받기, 권한이 허용된 공유의 파일 관리에 사용한다. 도구 설치는 2-2를 참고한다. 이 문서의 예시는 사용법을 설명한다. 실제 권한은 연결한 공유의 서버 설정이 결정한다. 운영 기록용 `logs` 공유는 읽기 전용이며 원격 변경 명령은 허용되지 않는다.

연결 대상의 일반 형식은 `smbclient //호스트/공유 [옵션]`이다. 서비스 목록은 `smbclient -L 호스트 --use-kerberos=required`로 확인한다. 관리형 워크스테이션의 로그인 세션에는 사내 Kerberos 티켓이 제공되며, `--use-kerberos=required`는 그 세션을 사용하도록 강제한다. `-N`은 암호 질문을 생략하는 옵션일 뿐 접근 권한을 부여하지 않는다. 이 공유에서는 Kerberos 세션이 필요하므로 `-N`만으로는 접속할 수 없다. 티켓이 만료되거나 다른 공유의 권한이 없으면 접속이 거부된다. 비밀번호를 명령 이력에 넣지 않는다. 원격 명령 한 번을 실행하고 끝내려면 `-c '명령'`을 사용한다.

```sh
smbclient -L dev-files.root.internal --use-kerberos=required
smbclient //dev-files.root.internal/logs --use-kerberos=required
smbclient //dev-files.root.internal/logs --use-kerberos=required -c 'ls'
```

## 연결 옵션과 공유 확인
| 옵션 | 용도 | 사용 시 주의 |
| --- | --- | --- |
| `-L 호스트` | 해당 호스트의 공유 이름과 유형 표시 | 공유 목록이 보여도 각 공유의 파일 권한까지 생기지는 않는다. |
| `--use-kerberos=required` | 기존 Kerberos 티켓으로 인증하고 다른 인증 방식으로 내려가지 않음 | 관리형 워크스테이션의 업무 세션에서 사용한다. |
| `-c '명령; 명령'` | 대화형 프롬프트 없이 명령을 차례로 실행 | `cd`, `ls`, `get`처럼 순서에 따라 원격 현재 위치가 바뀐다. |
| `-V`, `--version` | 클라이언트 버전 표시 | 패키지 진단용이다. |
| `-N` | 암호 질문을 생략 | Kerberos 티켓이나 공유 권한을 대신하지 않는다. |

`public`은 팀 공용 자료를 위한 공유이고, `projects`는 담당자에게만 열린다. `logs`는 기록 검토용 읽기 권한만 제공한다. `smbclient -L`에서 보이는 이름을 `cd` 인수로 쓰지 않는다. 공유 이름은 접속할 때 선택하고, 접속한 뒤의 `cd`는 그 공유 안의 디렉터리를 이동한다.

## 프롬프트와 경로
접속하면 `smb: \>` 형태의 프롬프트가 표시된다. `pwd`는 원격 현재 폴더, `lcd`는 로컬 저장 폴더를 바꾸거나 현재 위치를 보여 준다. `cd auth`로 이동한 뒤 `get 파일명`을 실행하면 원격 `auth/` 파일이 로컬 작업 폴더로 내려온다. 디렉터리 이름과 파일명은 `ls`로 확인한다. `get`의 선택적 두 번째 인수로 로컬 파일명을 지정할 수 있다. 연결을 끊으려면 `exit` 또는 `quit`를 입력한다.

## 빠른 명령 색인
| 명령 | 뜻 | `logs` 공유에서 |
| --- | --- | --- |
| `help`, `?`, `help 명령` | 전체 또는 특정 명령 설명 | 가능 |
| `ls [패턴]`, `dir [패턴]` | 원격 파일·폴더 목록 | 가능 |
| `cd 디렉터리` | 원격 현재 폴더 이동 | 가능 |
| `pwd` | 원격 현재 경로 표시 | 가능 |
| `lcd [디렉터리]` | 로컬 저장 폴더 변경; 인수가 없으면 현재 경로 표시 | 가능 |
| `get 원격파일 [로컬파일]` | 파일 하나 내려받기 | 가능 |
| `mget 패턴` | 일치하는 파일 여러 개 내려받기 | 가능 |
| `more 파일` | 원격 텍스트 내용 확인 | 가능 |
| `allinfo 파일` | 파일의 원격 메타데이터 확인 | 가능 |
| `prompt` | `mget`의 파일별 확인 전환 | 가능 |
| `recurse` | `mget`의 하위 폴더 순회 전환 | 가능 |
| `mask 패턴` | 재귀 전송 시 파일 필터 | 가능 |
| `history` | 연결 중 입력한 명령 목록 | 가능 |
| `exit`, `quit` | 연결 종료 | 가능 |
| `put`, `mput` | 원격 공유에 업로드 | 읽기 전용으로 거부 |
| `mkdir`, `md`, `rmdir`, `rd` | 원격 폴더 생성·삭제 | 읽기 전용으로 거부 |
| `del`, `rm`, `rename` | 원격 파일 삭제·이름 변경 | 읽기 전용으로 거부 |

`mget`은 `prompt` 설정과 `recurse` 설정에 영향을 받는다. 여러 파일을 받기 전에 현재 원격 디렉터리와 로컬 저장 디렉터리를 확인한다. 패턴 `*`는 범위가 넓으므로 조사에 필요한 날짜나 접두어로 범위를 줄인다. 원격 기록을 수정하는 명령은 읽기 전용 공유에서 시도해도 거부된다.

## 여러 파일과 로컬 작업 폴더
`mget`은 현재 원격 디렉터리에서 패턴에 맞는 파일을 받는다. 기본값은 파일마다 `Get file ...?`로 확인한다. 일괄 수집이 승인된 작업이라면 `prompt`로 확인을 끈 후 좁은 패턴을 지정한다. 같은 명령을 다시 입력하면 확인이 다시 켜진다. `lcd`는 다운로드 목적지를 바꾸며 원격 폴더는 바꾸지 않는다.

```text
smb: \auth\> lcd /home/analyst/Downloads
smb: \auth\> prompt
prompting is now off
smb: \auth\> mget auth-2026-09-2?.log
```

`recurse`는 하위 디렉터리까지 수집할 때 사용한다. 재귀 모드에서 `mget`의 인수는 탐색할 디렉터리 범위가 되고, `mask`는 받을 파일명을 거른다. 예를 들어 공유의 루트에서 `recurse`, `mask *.log`, `mget auth` 순서로 실행하면 `auth/` 아래의 로그 파일을 대상으로 한다. 작업 후에는 `recurse`를 다시 실행해 재귀 모드를 끄고 `mask *`로 필터를 되돌린다. 넓은 패턴의 일괄 다운로드는 불필요한 기록까지 개인 홈에 복사할 수 있다.

## 작업 순서 예시
```text
smb: \> ls
smb: \> cd auth
smb: \auth\> ls
smb: \auth\> get auth-2026-09-23.log
smb: \auth\> get auth-2026-09-24.log
smb: \auth\> exit
```

위 날짜는 경로 표기 예시이며 사건의 조사 범위를 지정하지 않는다. 내려받은 사본은 `~/Downloads`에서 확인한다. 기록 종류별 위치는 3-1, 파일 해석과 출처 기재는 4-1을 따른다.

## 자주 발생하는 오류
`NT_STATUS_BAD_NETWORK_NAME`은 공유 이름 또는 대상 서비스의 오류일 수 있다. `NT_STATUS_ACCESS_DENIED`는 권한 문제다. `NT_STATUS_OBJECT_NAME_NOT_FOUND`는 현재 원격 디렉터리에서 파일명을 찾지 못했다는 뜻이다. `smb://` 주소를 Dolphin에 입력해 발생한 오류는 별개이며, 이 워크스테이션에는 KDE SMB KIO worker가 제공되지 않는다. 도구 설치 여부와 서버 접근 권한을 혼동하지 않는다.
