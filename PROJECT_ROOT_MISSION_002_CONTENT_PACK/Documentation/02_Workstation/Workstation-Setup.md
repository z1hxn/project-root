# Workstation Setup

표준 분석 워크스테이션은 Debian GNU/Linux와 KDE Plasma를 사용한다. 기본 도구에는 Dolphin, Konsole, Firefox와 PROJECT ROOT 클라이언트가 포함된다.

사용자 파일은 `/home/<user>` 아래에 저장한다. 조사 중 내려받은 자료는 원본을 수정하지 않고 Downloads 또는 사건별 작업 디렉터리에 복사하는 것을 권장한다.

추가 CLI 도구가 필요한 경우 임의 바이너리를 내려받지 말고 승인된 APT repository의 패키지를 사용한다. 설치 절차는 `Package-Installation.md`를 참고한다.
