# Network Resources

아래 이름은 내부 DNS에서만 해석되는 PROJECT ROOT 리소스다.

| Resource | Hostname | Purpose |
|---|---|---|
| Documentation | docs.root.internal | 내부 운영/기술 문서 |
| Development Storage | dev-files.root.internal | 개발 프로젝트 및 운영 기록 저장 |
| Build Storage | build.root.internal | 빌드 산출물 및 runner 자료 |
| Archive | archive.root.internal | 장기 보존 자료 |

서비스마다 지원 프로토콜과 권한이 다르다. Development Storage의 파일 공유 방식은 `Development-Storage.md`를 확인한다.
