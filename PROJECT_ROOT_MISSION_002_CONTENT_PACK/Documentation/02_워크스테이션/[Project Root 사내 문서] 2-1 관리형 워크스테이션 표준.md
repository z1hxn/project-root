# [Project Root 사내 문서] 2-1 관리형 워크스테이션 표준

문서 번호: PR-IT-2-1 | 담당: 엔드포인트 운영팀 | 적용일: 2026-09-01 | 개정: 3.0 | 등급: 사내

## 표준 환경
조사관에게 제공되는 데스크톱은 Debian 기반의 관리형 KDE Plasma 이미지다. Dolphin은 로컬 개인 파일과 배포된 사내 문서, 사례용으로 제공된 내보내기 자료를 열 때 사용한다. Konsole은 패키지 확인과 승인된 서비스 클라이언트 실행에 사용한다. Firefox는 외부 공개 기록을 확인한다. 이 구분은 프로그램의 우열이 아니라 데이터의 제공 방식에 따른 것이다.

## 네트워크 위치 표시
Dolphin의 ‘네트워크’에 보이는 PROJECT ROOT 영역은 문서 및 내보내기 자료의 목록이다. 내부 서비스의 주소와 역할은 개발팀 문서 3-1에 등록하며, SMB 파일 시스템은 Dolphin의 네트워크 위치에 마운트하지 않는다. KDE에서 일반적인 `smb://호스트/공유` 탐색은 KIO의 SMB worker가 처리한다. 이 관리형 이미지에는 해당 worker를 제공하지 않으므로 Dolphin에서 SMB 주소를 열어도 공유 파일 목록이 나오지 않는다. 경로 표시가 된다는 사실과 공유에 접근할 수 있다는 사실은 다르다.

운영 기록 공유는 워크스테이션 로그인 시 발급된 사내 Kerberos 세션을 사용하는 Samba 명령행 클라이언트로 읽는다. Kerberos 티켓은 개인 비밀번호를 명령행에 다시 입력하지 않고 서버가 접근 주체를 확인하도록 한다. 클라이언트의 설치와 사용은 2-2, 3-2에 정리되어 있다. Dolphin에서 접근 오류가 날 때 임의의 마운트 명령이나 개인 자격 증명 저장으로 우회하지 않는다. 로컬에 내려받은 사본은 Dolphin에서 열 수 있다.

## 기본 위치와 작업 방식
- `~/Documents`: 개인 조사 메모. 원본과 해석을 혼동하지 않도록 파일명을 구분한다.
- `~/Downloads`: 승인된 도구로 받은 작업 사본. 동일 파일명으로 다시 받으면 내용을 확인한다.
- 네트워크 문서: 조직에서 배포한 읽기 전용 기준 문서.
- 사례 내보내기: 검토용으로 별도 제공된 읽기 전용 자료. 중앙 저장소의 전체 내용을 대신하지 않는다.

워크스테이션의 기본 폴더와 사내 배포 영역은 사용자가 삭제·이동할 수 없다. 필요하지 않은 개인 사본은 조사 노트와 대조 후 정리한다.
